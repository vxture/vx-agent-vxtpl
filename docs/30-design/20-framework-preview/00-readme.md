## 2. 已固定的框架规则

- 中栏不能禁用、收起或隐藏，空内容显示有效空状态。左右栏隐藏后释放空间。
- 五类框架采用同一套外壳与中内容布局。预览工具的「内容上限」可在同一视口切换 1536px 和 1920px。尺寸、停靠侧栏和两种视口分配见[全局布局框架约定](../10-template-foundation.md#50-全局布局框架约定)。
- 小屏辅助栏改为抽屉，同一时刻展示一个；Esc 可以关闭，键盘焦点留在打开的抽屉内。
- 文档分栏切换、恢复覆盖层关闭不重建中栏。笔记只保留在本页内存，刷新或关闭后清除。
- 业务中栏先占满实际可用空间，再在中栏内部应用内容上限及左右留白。页头、正文、笔记输入框及独立对话区沿同一组内容边线铺满，组件无需再设固定宽度。
- 人员头像与姓名作为单行行内组件，继承所在行的字号和行高。头像直径跟随字号，图像和姓名垂直居中，长姓名在同一行截断并保留完整文本。
- 专注模式与浏览器全屏分别控制；切换时保留原舞台节点，退出专注恢复面板状态。
- 工作 Header 的 AI 按钮打开右侧助手。桌面贴着 Header 下沿停靠，窄档 420px，可切换宽档。窄窗用右侧抽屉。由左到右提供宽窄切换、新对话、全部对话、更多操作、关闭。宽窄切换沿用 Yucer 的水平外扩和内收图标。空会话的欢迎区靠上显示低对比星星图标和文案，开始对话后回复只显示正文。关闭重开或从历史切换会话时保留消息和输入草稿。助手和独立对话均使用离线示例回复。
- AI 入口默认透明。悬停、按下和侧栏展开使用 32px 圆形底色和轻微光晕，G2 外层保持透明。工作 Header 用低饱和品牌蓝，地图 Header 沿用地图强调色。键盘聚焦有独立的圆形指示。
- 组织、账号、订阅、使用资格和登录按钮仅展示设计流程，不能作为真实权限或认证结果。
- 产品配置中的名称作为文本呈现，不解释为 HTML。布局适配只改变品牌和内容，不更改中栏约束。
- 整组共用框架名为“门禁页面”；登录、恢复、资格不足等保留各自的状态标题。
- 独立门禁页和公开首页固定保留卡片外的上方产品定位、下方产品介绍与英文副句，20 种状态共用同一结构。
- 门禁与公开首页的 Header 右上使用“主题、语言、全屏、平台主站”按钮组；整体与单项均有悬停/键盘聚焦反馈，手机仍保持四项成组。
- 产品显示名默认 `Vxtpl`，可通过“产品适配”自定义；内部产品标识仍为 `vxtpl`。上下文案可一并配置，CoSpace 预设沿用原套件文案。
- 最近工作按更新时间排序，桌面及 640px 以上每行三张，最多两行。紧凑两列和手机单列同样最多两行。“全部工作”展示完整清单，共九个样例。
- 工作概览的主标题有 10 条，按浏览器当地日期轮换。顺序随机排定，同一天刷新沿用同一句，每轮 10 天不重复，句尾统一省略句号。
- 分段进度上方左侧显示当前阶段短语，右侧显示完成百分比。线段排满卡片可用宽度，段间距为 2px。当前段用实心主色并略长，已完成段用淡主色，未开始段用中性灰。辅助技术可读取各段名称与状态。
- 阶段、完成百分比和工作状态分别取自对应数据。未提供有效总量时，百分比显示“—”。
- 阶段标签前使用 12px DS 图标。校对、确认、评审和访谈可指定图标，其他阶段按进行中、已完成、未开始选用默认图标。
- 时间采用单行“更新 · 今天 11:40”，与进入按钮同排。卡片背景按工作状态使用蓝、琥珀、绿或中性灰的连续渐变，适配深浅主题。细边线和顶部短色标沿用卡片装饰色。
- 最近工作标题区参照 DS 二级 `SectionHeader`，主标题 16px/600，副标题 12px，右侧为轻量“全部工作”链接。类型采用无底无框图标，负责人行紧接简介，卡片底部使用纯文字“进入”。
- 产品 Header 使用 `--spacing-header-md`（48px）。工作导航参照 Ruyin Work，宽屏紧跟组织入口靠左，900px 及以下单列在主栏下方。导航使用 14px/500 文本，项间 24px，当前项以主色标识。
- 工作 Header 从左到右分组为 G1 搜索、G2 AI、G3 主要操作、G4 账号。工具控件使用 `--space-control-md`（32px），AI 星形使用 `--spacing-icon-lg`（24px），头像填满 32px 圆形，普通工具图标为 16px。G3 的基础操作顺序为主题、语言、全屏、主站。业务面板及画布专注操作在基础操作之前。窄屏将 G3 收入“主要操作”面板，四组入口均保留。
- 组织入口使用 DS `ShellScopeButton` 的结构。按 Yucer 实测，组织名使用 DS 字体栈、14px/400、20px 行高和前景色。工作空间使用 12px/400、16px 行高及中性次要前景色，中间用中点隔开。AI 星形图标默认使用同一中性次要前景色。展开为锚定的 320px `ShellPanelContent` 样式面板，保留组织身份、资源、组织信息和两级范围选择。
- 组织与工作空间选项仅切换本地预览标签，资源数值均为样例；正式产品必须使用已授权的真实范围和资源数据。
