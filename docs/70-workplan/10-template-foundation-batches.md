## 5. T4 验收矩阵

| 组 | 场景 | 必须证明 |
| --- | --- | --- |
| 登录 | 密码/钉钉、已有 SSO、匿名静默、深链、取消/过期/重放 | 不循环；原目标保留；失败不生成成功会话 |
| 退出 | 本站/其他产品/Accounts 退出、重试、在途刷新 | 原会话持久失效；不能写回复活；新登录可建立独立新会话 |
| 双域/多设备 | 客户与运营同时有效；不同浏览器设备 | 两域互不误伤；普通退出范围准确，不误称退出所有设备 |
| 准入 | 有订阅未分配、分配/撤销/再分配、停用、普通成员 | 资格归平台；旧本地角色不能绕过；基础成员可用其有权功能 |
| 上下文 | 切组织/空间、旧请求返回、恢复后换账号 | 无跨范围读写/展示/草稿泄漏 |
| 事件 | 重复/乱序、ACK 丢失、游标缺口、快照并发 | 可靠确认、版本单调、完整恢复、无越权事件 |
| 故障 | 网络、PG/Redis、代理/进程恢复、休眠唤醒 | 503 区分失效；正确阻止敏感操作；恢复不依赖人工刷新 |
| 流量 | 健康 SSE、普通切 tab、静置两个原周期 | 无浏览器周期身份/权益查询；心跳不冒充用户活动 |
| 首页 | CoSpace 公开入口/工作概览、品牌替换、无/部分/失败数据 | 主题和内容可配置；只有真实有权入口；不将未知显示成正常 |
| 业务区域 | 四种有效组合、切换左右栏、窄屏、非法配置/旧偏好 | 中栏始终保留；主内容有可用宽度；无空列、草稿丢失或多重 main |
| 画布全屏 | 工作/专注/浏览器全屏、面板、弹层、Esc、拒绝全屏 | 舞台不重建；工具和恢复层可用；回退状态正确；无地图功能依赖 |
| 管理与助手 | 固定导航、内容滚动、助手开合、权限/上下文变化 | 中栏保留；面板不产生隐式请求或费用；导航不授予平台治理权 |
| 公共部件 | Header 独立/组合、Footer、门禁页面三种呈现、小屏/键盘 | 行为与身份源一致；无重复外壳；样例状态不进入生产授权路径 |
| 游戏 | 开局、扣额、结束、记录、榜单、全屏、退出 | 原业务完整；旧数据与计量归属保留；失败不伪报成功 |
| 创建/升级 | 两个新产品标识与不同业务形态、升级运行库及共用框架 | 无残留品牌/凭据/历史验收；不复制修改认证或框架源码即可复用与升级 |
| 发布 | CI、不可变镜像、迁移、版本、回滚 | 能关联每项证据到实际版本与环境 |

真实故障、权限变更及测试成员使用仅在实施时明确的测试范围进行；本轮未执行这些操作。
